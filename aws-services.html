Essential AWS Services

Start with the services used in everyday cloud and DevOps work.

Compute

Amazon EC2

Run virtual servers in the AWS cloud. Configure operating systems, networking, storage and security groups.

Storage

Amazon S3

Store files, images, backups and static website assets in highly durable object storage.

Networking

Amazon VPC

Create an isolated virtual network with subnets, route tables, gateways and network security controls.

Security

AWS IAM

Manage identities, roles and permissions so workloads and people receive only the access they need.

Database

Amazon RDS

Run supported relational databases with managed backups, maintenance and monitoring capabilities.

Monitoring

Amazon CloudWatch

Collect metrics and logs, create alarms and monitor the health of cloud resources and applications.

How a cloud application works

Users access an application → Load Balancer distributes traffic → EC2 runs the application → RDS stores relational data. Files can be stored in S3, while CloudWatch helps monitor the system.
