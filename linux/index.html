Linux Commands Cheat Sheet

Learn the commands commonly used to manage files, permissions, processes, services and networking on Linux servers.

Ubuntu · EC2 · DevOps

1. Navigate files and directories

pwd                 # Show current directory
ls -lah             # List files, including hidden files
cd /var/www         # Change directory
mkdir demo          # Create a directory
touch index.html    # Create an empty file
cp file.txt copy.txt
mv old.txt new.txt
cat index.html      # Display file contents

2. File permissions

ls -l                       # View permissions
chmod 644 index.html        # Owner writes; others read
chmod 755 script.sh         # Executable permissions
sudo chown ubuntu:ubuntu file.txt

Use the minimum permissions required. Avoid making files writable by everyone unless there is a specific reason.

3. Processes and system resources

ps aux                 # List processes
top                    # Monitor processes
free -h                # Memory usage
df -h                  # Disk space
du -sh /var/www        # Directory size
uptime                 # System uptime

4. Services and logs

sudo systemctl status nginx
sudo systemctl restart nginx
sudo systemctl reload nginx
sudo journalctl -u nginx --since today
sudo nginx -t

Test Nginx configuration with nginx -t before reloading it after a configuration change.

5. Networking

ip addr                 # Show network addresses
ip route                # Show routes
ss -lntp                # Show listening TCP ports
curl -I http://localhost/
curl -I http://localhost:8080/
ping -c 4 8.8.8.8       # Test basic network reachability

6. Package management

sudo apt update
sudo apt upgrade
sudo apt install nginx
sudo apt remove package-name

Review package changes before confirming upgrades or removals on a production server.

7. Git basics

git status
git branch
git switch -c feature/my-change
git add .
git commit -m "Update website"
git push -u origin feature/my-change

Review changes before using git add ., especially when working with secrets or configuration files.
