Virtual Private Cloud

What is a VPC?

An Amazon Virtual Private Cloud (VPC) is a logically isolated network in AWS. You choose an IPv4 CIDR range and configure subnets, routes and network access controls.

Important networking components

CIDR Block

Defines the IP address range for a VPC or subnet. Example: 10.0.0.0/16.

Subnets

Divide a VPC address range into smaller networks associated with individual Availability Zones.

Route Tables

Determine where network traffic is directed, using destination ranges and targets such as gateways.

Internet Gateway

Allows eligible resources to communicate with the internet when routes and public IP addressing permit it.

Security Groups

Act as stateful virtual firewalls attached to network interfaces to control inbound and outbound traffic.

VPC Peering

Connects two VPCs for private IP communication. Their CIDR ranges must not overlap.

How VPC peering works

1. Create a peering connection request. 2. Accept the request from the other VPC owner when required. 3. Add routes to both VPC route tables. 4. Update security groups and network ACLs if needed. 5. Test connectivity between permitted private IP addresses.

Important: VPC peering does not automatically create routes or allow all traffic, and it does not support transitive routing.
