Understand Docker

Package an application and its dependencies into a portable container that can run consistently across environments.

This page is a learning guide, not a running container

Core Docker concepts

Docker Image

A read-only template containing application files, libraries and instructions used to create containers.

Docker Container

A running or stopped instance created from an image, isolated from other processes using OS-level features.

Dockerfile

A text file containing instructions for building an image, such as choosing a base image and copying files.

Docker Registry

A service that stores and distributes images. Docker Hub is one commonly used public registry.

Useful Docker commands

Check your Docker installation and inspect containers with these commands:

docker --version
docker pull nginx
docker images
docker run -d --name web -p 8085:80 nginx
docker ps
docker logs web
docker stop web
docker rm web

The example publishes container port 80 on host port 8085. Run it only on a machine where Docker is installed.

Typical workflow

Write a Dockerfile → Build an image → Test a container → Push the image to a registry → Deploy it to a server.
